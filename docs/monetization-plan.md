# Monetization Plan

## Product Ladder

### Tier 1 - Community Connector

Free or low-cost Odoo Marketplace addon.

Includes:

- Odoo connector settings.
- CRM and Projects enablement.
- Basic audit log.
- Self-hosted MCP instructions.

Goal:

Drive adoption and trust.

### Tier 2 - Pro Self-Hosted

Paid Odoo app or paid support subscription.

Includes:

- Supported Docker MCP server.
- CRM and Projects write tools.
- Advanced audit logs.
- Upgrade support.
- Email support.

Goal:

Monetize companies that want control but need reliability.

### Tier 3 - Managed Cloud

Recurring subscription.

Includes:

- Hosted MCP service.
- Managed updates.
- Monitoring.
- Backups for audit logs.
- Teams and Google Chat bridges.

Goal:

Create recurring revenue and reduce customer deployment burden.

### Tier 4 - Enterprise

Custom pricing.

Includes:

- SSO.
- Private deployment.
- Custom Odoo modules.
- Security reviews.
- SLA.
- Priority support.

Goal:

Serve larger companies with security and compliance needs.

## Recommended Launch Pricing Hypothesis

| Plan | Price Hypothesis | Notes |
|---|---:|---|
| Community | Free or 49 USD | Marketplace adoption |
| Pro Self-Hosted | 299-799 USD per Odoo version | One-time plus support option |
| Managed Team | 49-199 USD/month | Based on user count and features |
| Enterprise | Custom | SSO, private hosting, SLA |

## Packaging Recommendation

Start with:

- Free marketplace connector.
- Paid implementation/support.
- Paid managed MCP service once internal deployment is stable.

This reduces buyer friction while preserving a strong path to recurring revenue.
